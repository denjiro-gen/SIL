========================================================================
 SIL Spring Boot REST API - Postman Testing Guide
 Hands-On Activity: Spring Boot Security, RBAC & Global Exception Handling
========================================================================

PREREQUISITES
-------------
1. Spring Boot app running on http://localhost:8080
   - Use VS Code (Java Extension Pack) > Run "ApiApplication.java"
   - OR from terminal: mvn spring-boot:run

2. MySQL running with database "mydb_api"
   - XAMPP: Start Apache + MySQL from XAMPP Control Panel

3. Import Postman_Collection.json into Postman
   - Open Postman > Import > Choose Postman_Collection.json


========================================================================
 STEP-BY-STEP TESTING GUIDE
========================================================================

STEP 1: LOGIN AS ADMIN
-----------------------
Request : POST /api/auth/login
Body    :
  {
    "username": "admin",
    "password": "admin123"
  }
Expected: 200 OK
Response:
  {
    "token": "eyJhbGci...",
    "type": "Bearer"
  }
✅ The Postman collection auto-saves this token to {{adminToken}}


STEP 2: LOGIN AS STUDENT
--------------------------
Request : POST /api/auth/login
Body    :
  {
    "username": "alex_mercer",
    "password": "password123"
  }
Expected: 200 OK
✅ The Postman collection auto-saves this token to {{studentToken}}

========================================================================
 ERROR RESPONSE TESTING
========================================================================

TEST A: 401 Unauthorized (no/invalid token)
  - Any protected endpoint without Authorization header
  - Expected: 401 + {"timestamp":"...","status":401,"error":"Unauthorized","message":"...","path":"..."}

TEST B: 403 Forbidden (wrong role)
  - STUDENT token hitting ADMIN-only endpoint
  - Example: GET http://localhost:8080/api/courses with STUDENT token
  - Expected: 403 + {"timestamp":"...","status":403,"error":"Forbidden","message":"...","path":"..."}

TEST C: 404 Not Found
  - GET http://localhost:8080/api/students/999
  - Expected: 404 + {"timestamp":"...","status":404,"error":"Not Found","message":"Student with ID 999 was not found.","path":"..."}

TEST D: 409 Conflict (duplicate)
  - POST /api/students with existing email or username
  - Expected: 409 + {"timestamp":"...","status":409,"error":"Conflict","message":"Email '...' is already registered.","path":"..."}

TEST E: 400 Bad Request (validation fail)
  - POST /api/students with missing required fields
  - Body: {"email":"test@test.com"}  ← missing name, username, password
  - Expected: 400 + {"timestamp":"...","status":400,"error":"Bad Request","message":"Name is required, ...","path":"..."}

========================================================================
 CLONING & RUNNING ON ANOTHER MACHINE
========================================================================

1. Clone:
   git clone https://github.com/denjiro-gen/SIL.git
   cd SIL

2. Install Requirements:
   - Java 17 (Eclipse Adoptium / Temurin)
   - Maven 3.8+
   - MySQL / XAMPP (MariaDB)

3. Create database:
   mysql -u root -p
   CREATE DATABASE mydb_api;

4. Update src/main/resources/application.properties:
   spring.datasource.password=YOUR_MYSQL_PASSWORD  ← if you have a password

5. Run:
   mvn spring-boot:run
   OR open in VS Code and run ApiApplication.java

6. Flyway auto-runs all 3 migrations (V1, V2, V3)
   Seeder ensures admin and alex_mercer credentials are BCrypt-hashed

7. Test: http://localhost:8080/api/auth/login
